# WashEasee

WashEasee is a mobile-first laundry subscription website built with React, Vite, and Tailwind CSS.

## Run locally

```powershell
cd app
npm install
npm run dev
```

## Build

```powershell
cd app
npm run build
```

The production files are generated in `app/dist`. For Vercel, set the project root directory to `app`.
